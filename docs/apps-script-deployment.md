# Apps Script deployment

`.github/workflows/deploy-apps-script.yml` deploys the Apps Script project with
`clasp` after every push to `main`, regardless of which client or chat created
the commit. It can also be run manually with **Actions → Deploy to Google Apps
Script → Run workflow**.

The workflow updates the existing deployment instead of creating a new one, so
the current public `/exec` URL is preserved. `scr/appsscript.json` remains the
source of the web-app access setting (`ANYONE_ANONYMOUS`).

## Required repository settings

Configure these once in the repository’s **Settings → Secrets and variables → Actions**:

- Secret `CLASP_TOKEN`: the contents of the local `.clasprc.json` generated by
  `clasp login`. Add it as a secret, never commit it to the repository.
- Variable `CLASP_DEPLOYMENT_ID`: the existing Apps Script deployment ID used
  by the public `/exec` URL. This is a variable, not a credential.

One-time CLI setup (run locally with an authenticated `gh` account) is:

```bash
gh secret set CLASP_TOKEN --repo jrh91234/Coil-winding < "$HOME/.clasprc.json"
gh variable set CLASP_DEPLOYMENT_ID --repo jrh91234/Coil-winding \
  --body "<existing deployment ID>"
```

If `CLASP_TOKEN` is not already configured, the user must run `clasp login`
once and add the resulting file as the repository secret. The workflow fails
with an explicit error before any deployment attempt when either setting is
missing.
